# Resume Bullets

- Built a synthetic healthcare claims analytics pipeline using SQL/SQLite, Python (Pandas/NumPy), and Power BI-ready outputs across 20K patients and 75K+ claim records.
- Developed 36 SQL analyses covering payer mix, claim status, provider/facility performance, denial rates, utilization, submission lag, financial integrity, procedure concentration and monthly trends.
- Implemented explainable anomaly screening using P99 claim values, provider weekly volume baselines, financial exceptions and missing-provider checks; evaluated the rules against separate synthetic validation labels.
- Built data-quality checks for duplicate claims, missing fields, date logic, financial inconsistencies, referential integrity and claim header/line reconciliation.
